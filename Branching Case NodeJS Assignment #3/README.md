
# Branching Case - Node.js Assignment #3

## Description
This project contains eight JavaScript exercises about branching
and conditional statements using Node.js.

## Exercises

### Level 1
- Exercise 2: Even or Odd
- Exercise 3: Pass or Fail

### Level 2
- Exercise 6: Grade Category
- Exercise 7: Largest of Two Numbers

### Level 3
- Exercise 12: Student Passing Check
- Exercise 13: Free Shipping

### Level 4
- Exercise 16: Parking Fee
- Exercise 18: Cashier Program

## Requirements
- Node.js

## How to Run
Open the terminal in this folder and run a file using:

node L1_Ex2_Even_or_Odd.js

Replace the filename with the exercise you want to run.
